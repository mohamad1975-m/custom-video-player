تولید دستور از لینک درس

راهنما:

  • فقط لینک صفحهٔ درس را بده؛ مثل: https://www.harfeakhar.tv/education/lesson/9XH9qG
  • ابزار خودش لینک index-v1-a1.m3u8 را می‌سازد.
  • مطمئن شو ffmpeg.exe آماده است (اگر نداری: دانلود ffmpeg.exe)
اسکریپت CMD 

      

    


    
    

      
اگر اولی کار نکرد: استفاده از لینک m3u8

      

        
راهنمای گرفتن لینک m3u8:

        
    
          
  • در صفحه درس، کلید F12 را بزن (بخش Inspect).
    • 
          
  • روی تب Network کلیک کن و ویدیو را پخش کن.
    • 
          
  • در لیست Network، روی index-v1-a1.m3u8 راست‌کلیک کن → Copy → Copy URL.
    • 
          
  • لینک کپی‌شده را اینجا بچسبان.
    • 
          
  • مطمئن شو ffmpeg.exe آماده است (اگر نداری: دانلود ffmpeg.exe)
